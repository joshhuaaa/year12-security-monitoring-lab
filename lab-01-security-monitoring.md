# Lab 1 — Basic Security Monitoring

## Objective

The aim of this lab understanding how security monitoring can be used to identify and investigate suspicious activity on a computer

## Scenario

A security analyst is monitoring a computer for unusual authentication activity.

In this lab i am going to demonstrate:

- Collecting security events
- Identifying failed authentication attempts
- Investigating the events
- Understanding why repeated failures may be suspicious
- Documenting the investigation

## Skills

- Basic security monitoring
- Log analysis
- Authentication events
- Incident investigation
- Security documentation

## Investigation

### Event

A number of unsuccessful login attempts were detected

### Questions

1. When did the events occur?
2. What account was involved?
3. Where did the attempts originate?
4. How many failed attempts occurred?
5. Could the activity indicate suspicious behaviour?

## Conclusion

This lab demonstrates the basic process a security analyst can use to identify an event, investigate the available information and determine whether further investigation is required.
